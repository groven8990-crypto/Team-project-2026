# 업무 공유 (가제)

유통 팀의 업무를 한곳에서 공유·구조화하는 웹앱입니다. 별도 설치 없이 브라우저에서 바로 동작하고, 키만 넣으면 팀원과 **실시간 공유 모드**로 전환됩니다.

> 제목 "업무 공유"는 가제입니다. 나중에 `assets/js/config.js` 의 `APP_TITLE` 값만 바꾸면 됩니다.

## 주요 기능

| 메뉴 | 설명 |
|------|------|
| 🗂️ **할일 대시보드** | 할 일 / 진행 중 / 완료 칸반 보드. 담당자·마감일 지정, 한 번에 상태 이동, 통계 |
| 📅 **캘린더** | 월간 달력 + **주별/월별 일정**을 달력 위에 별도로 강조 표시. 날짜 칸 클릭으로 바로 추가 |
| 📚 **데이터 보드** | **자료실**(사진/이미지 업로드·링크), **미팅**, **아이디어 노트**, **링크** |
| 📝 **회의록** | 참석자·안건·내용·결정사항 기록 (데이터 보드의 '미팅'과 같은 데이터) |
| 🔁 **KPT 회고** | 유지할 것(Keep)·문제점(Problem)·개선점(Try). **"내가 쓴 회고만 보기"** 필터 |
| 📈 **일일 보고서** | 하루 업무를 보고서로 작성·공유. **오늘 활동 자동생성**, 텍스트 복사 |
| 👥 **멤버** | 팀원 이름·색상 등록. 담당자/작성자 표시, 회고 필터에 사용 |

모든 항목에 **추가 / 수정 / 삭제 / 완료(체크)** 버튼이 들어 있습니다.
우측 상단에서 **본인 이름**을 선택하면 작성자·담당자 기본값으로 들어갑니다.

## 바로 사용하기 (로컬 모드)

`index.html` 을 브라우저로 열기만 하면 됩니다. 데이터는 그 브라우저에만 저장됩니다.
- 인터넷에 올려두고 쓰려면 GitHub Pages 가 가장 간단합니다 (아래 참고).
- 로컬 모드에서는 우측 상단 ⚙️ 메뉴로 데이터를 JSON 으로 내보내/가져와 팀원과 주고받을 수 있습니다.

## 팀원과 실시간 공유하기 (클라우드 모드) — 권장

각자 브라우저에 따로 저장되는 로컬 모드와 달리, **모두가 같은 데이터를 실시간으로** 보고 수정합니다.

1. [supabase.com](https://supabase.com) 에서 무료 프로젝트 생성
2. **SQL Editor** 에서 `supabase/schema.sql` 전체를 붙여넣고 **Run**
3. **Project Settings → API** 에서 `Project URL` 과 `anon public` 키 복사
4. `assets/js/config.js` 의 아래 두 값에 붙여넣기:
   ```js
   SUPABASE_URL: "https://xxxx.supabase.co",
   SUPABASE_ANON_KEY: "eyJhbGci...",
   ```
5. 끝! 새로고침하면 상단에 **● 실시간 공유** 배지가 뜨고, 팀원이 같은 주소를 열면 즉시 동기화됩니다.

> 보안: anon 키 방식은 "링크를 아는 사람"이 읽고 쓸 수 있습니다. 사내에서만 주소를 공유하세요. 더 강한 보안이 필요하면 Supabase Auth 로그인을 붙일 수 있습니다(추후 확장 가능).

## GitHub Pages 로 배포 (선택)

1. 이 저장소 **Settings → Pages**
2. Source: `Deploy from a branch`, Branch: 원하는 브랜치 / `/ (root)`
3. 몇 분 뒤 발급되는 주소를 팀원과 공유

## 폴더 구조

```
index.html              앱 진입점
assets/css/styles.css   디자인
assets/js/config.js     설정 (Supabase 키 / 앱 제목)
assets/js/store.js      데이터 저장소 (로컬 ↔ 실시간 자동 전환)
assets/js/ui.js         공통 UI (모달·토스트·포맷)
assets/js/app.js        화면·라우팅·기능 로직
supabase/schema.sql     실시간 공유용 DB 스키마
```

## 향후 확장 아이디어
- Supabase Auth 로그인(이메일/비번)으로 사용자별 권한 구분
- 자료실 이미지를 Supabase Storage 에 업로드(현재는 이미지 데이터 직접 저장)
- 보고서 자동 일/주간 집계, 알림
